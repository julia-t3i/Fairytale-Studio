## About 

FairyTale an iOS app built with SwiftUI that allows users to create their own interactive storybooks! Users can drag and drop characters, backgrounds, props, and text onto pages, upload their own assets, and build stories page by page!

## Installation & Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
* A Mac running **macOS 14.0+** (or your minimum macOS version)
* **Xcode 15.0+** (or your minimum Xcode version)
* An iOS Simulator or a physical iOS device running **iOS 17.0+**

### Step-by-Step Setup
1. **Clone the repository** to your local machine:
   ```bash
   git clone https://github.com
   ```
2. **Open the project** in Xcode:
   * Open Xcode, click **Open existing project**, and select the `.xcodeproj` file.
   * *Alternative:* If you use CocoaPods or Workspace, open the `.xcworkspace` file instead.

3. **Select a Target & Device**:
   * In the top toolbar, choose your app target and select an **iOS Simulator** (e.g., iPad 11-inch) from the device dropdown.

4. **Build and Run**:
   * Press `Cmd + R` or click the **Play (Run)** button in the top left corner of Xcode.
